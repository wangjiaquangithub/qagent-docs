# 对话、目标与工作区

## 输入栏与常用选项

对话输入栏用于选择本轮工作的模型及相关选项。常见选项包括：

- **模型**：选择当前对话使用的模型；
- **模式**：按任务性质切换工作方式；
- **预设角色**：让对话采用选定角色的职责和提示；
- **记忆**：控制是否在本轮引用可用记忆；
- **创意**：调整输出的发散程度；
- **工作空间**：限定本轮关联的工作内容；
- **Plan / 任务协作**：将较复杂的工作组织为可执行计划。

请在发送前检查是否包含密钥、私人文件内容或其他不应交给模型处理的信息。

## 使用目标

目标适合有明确交付物、完成条件或需要多步推进的工作。打开目标面板后，你可以：

1. 手动填写目标、约束和完成条件并启动；或
2. 让模型先生成执行方案，确认后再开始。

执行期间可查看阶段进展、补充要求或暂停工作。完成条件满足后，QAgent 会给出结果汇总；请在使用前自行审核结果。

## 右侧工作区

部分对话会在右侧工作区展示结构化结果、文件、表格、页面或其他可视化内容。工作区的具体内容由当前任务决定；重要信息应在保存、导出或删除前复核。
