# 预设角色与编码助手

## 预设角色

预设角色用于保存可复用的职责、工作方式和提示。可在 **预设角色** 页面创建、编辑、启用、停用或归档角色，并在对话中切换使用。

角色适合把重复的工作要求标准化，例如研究、写作、审阅或项目协作。角色不会替代你的审核责任；应避免把密钥、客户数据或未经授权的内容写入角色配置。

## 编码助手

如果当前 QAgent 版本提供编码助手或外部 CLI 集成，可在对话或任务协作中选择它完成代码相关工作。使用前请确认：

- 工作目录正确；
- 仓库权限和凭据已按组织规则配置；
- 自动执行命令、修改文件或访问网络的权限符合预期；
- 重要变更经过代码审查和测试。
