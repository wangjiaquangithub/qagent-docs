# 快速开始

## 1. 安装并打开 QAgent

从 [下载页](../../downloads.md) 获取官方安装包，完成安装后启动 QAgent。首次运行时，根据引导选择语言、外观等基础选项。

## 2. 配置模型

打开 **设置 → 模型**，按以下顺序完成配置：

1. 添加模型服务商；
2. 填写服务商提供的接口地址和访问密钥；
3. 在服务商下添加实际可调用的模型名称；
4. 选择一个主模型作为聊天和任务的默认模型；
5. 如界面提供连接测试，先测试成功再开始使用。

模型名称应与服务商控制台中的名称一致。密钥属于敏感信息，只应在本机受控输入框中填写。

## 3. 开始对话

在侧栏选择 **新建对话**，在输入区选择模型和所需选项，输入问题后发送。需要把复杂目标拆成可跟踪工作时，转到 [任务中心](tasks.md)。

## 4. 继续探索

- 需要设置对话选项、目标或工作区：阅读 [对话、目标与工作区](chat-and-goals.md)
- 需要配置重复执行的工作：阅读 [自动化](automations.md)
- 需要接入工具和技能：阅读 [技能与 MCP](skills-and-mcp.md)
