# 任务中心

任务中心用于创建、拆解、执行和跟踪较长的工作。

## 创建任务

在侧栏打开 **任务中心**，选择 **新建任务**，填写：

- **任务名称**：便于识别的简短标题；
- **任务描述**：目标、约束、输入材料和期望结果。

创建后，QAgent 可先分析任务并形成执行计划。请在开始执行前检查计划是否符合预期。

## 管理任务

任务列表通常支持按名称、描述或状态搜索，并显示任务状态与子任务进度。打开任务详情后可查看进展，并根据状态执行以下操作：

- 开始执行；
- 暂停或继续；
- 查看详情和实时输出；
- 批量选择、启动、暂停或删除。

删除任务前请确认其中没有需要保留的结果。任务中的模型输出、工具操作和外部副作用仍应由使用者负责复核。
