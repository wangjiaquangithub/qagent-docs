# 公开发布就绪门槛

本清单用于判断 QAgent 的公开安装包、安装说明和相关对外页面是否可以发布。它是发布前的证据与文档门槛，不是产品能力、平台支持或数据处理行为的声明。

> **当前状态：不得虚构。** 在存在可核验的正式构建和审查证据前，不要填写或暗示支持的平台、系统要求、下载链接、产品功能、联网行为、遥测行为或隐私处理方式。

## 一、安装包证据

公开前必须具备并留存与拟发布版本一一对应的证据：

- [ ] 已确定不可变的版本号、构建标识、构建时间和发布负责人。
- [ ] 已从受控的私有源码与可复现/可追溯的构建流程生成候选安装包。
- [ ] 已记录每个安装包的文件名、文件大小和 SHA-256；校验值已由独立步骤复核。
- [ ] 已完成目标平台上的安装、首次启动、更新（如提供）和卸载验证，并保留测试记录。
- [ ] 已完成恶意软件扫描、签名/公证或目标平台要求的等效分发安全检查，并记录结果与例外。
- [ ] 已确认安装包不包含密钥、访问令牌、个人数据、内部路径、调试产物或未获授权的第三方内容。
- [ ] 已明确正式分发渠道；二进制安装包作为 Release 附件或受控制品发布，不提交到本仓库。
- [ ] 已制定撤回、替换受损安装包和安全更新的处置流程及联系人。

## 二、安装说明文档门槛

在 `docs/install/` 编写正式说明前，必须基于已验证的正式安装包补齐：

- [ ] 支持平台、系统版本、硬件/运行时要求和不支持范围，均有测试依据。
- [ ] 官方下载入口、版本号、发布日期、文件名和 SHA-256，与实际 Release 完全一致。
- [ ] 可复现的安装、首次启动、更新和卸载步骤，且已在相应平台验证。
- [ ] 必要权限、安全提示、已知限制和常见失败场景，均对应当前版本的实测结果。
- [ ] 支持与安全问题的联系渠道已经实际可用；不得要求用户在公开渠道提交密钥或私人数据。
- [ ] 页面链接、截图、示例和命令均已复核，不含内部地址、个人路径、测试账号、密钥或未公开界面。

## 三、关联对外文档门槛

公开安装说明不得脱离下列经审查的配套内容：

- [ ] 对应版本的发行说明：仅描述已验证的用户可见变更、已知限制、下载入口和校验信息。
- [ ] 隐私与数据说明：基于实际版本的数据流审查，说明适用的数据处理、联网、遥测、崩溃报告、第三方服务、存储与保留情况；没有证据时不得作出“不会收集”“完全离线”等声明。
- [ ] FAQ、使用指南与故障排查：仅包含已验证的用户流程和问题处理方法。
- [ ] 如适用，已完成安全、法务、第三方许可证、商标与出口/地区合规审查，并记录批准或明确例外。
- [ ] 发布负责人已确认全部公开页面与同一版本安装包一致，且不存在未获证实的承诺。

## 四、发布批准记录

每次正式发布应在受控的内部发布记录中保留以下信息：

- 版本号、构建标识、发布日期和发布负责人；
- 安装包清单、SHA-256、签名/公证状态及分发位置；
- 测试、隐私/数据流、安全、许可证与法务审查的证据链接或记录编号；
- 已知限制、例外、风险接受人和撤回方案；
- 对外文档复核人及复核日期。

只有所有适用项目完成、例外获得明确批准且对外内容与证据一致时，才可发布安装包和正式安装说明。
