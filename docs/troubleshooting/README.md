# 故障排查

## QAgent 无法启动

1. 确认安装包来自 [官方下载页](../../downloads.md)；
2. 核对下载文件的 SHA-256；
3. 退出旧实例后重新打开 QAgent；
4. 确认系统版本满足对应发行说明中的要求；
5. 阅读该版本的已知限制。

## 模型无法调用

检查服务商地址、访问密钥、模型名称、网络连接和账户配额。模型名称应与服务商控制台中显示的名称完全一致；如提供连接测试，先运行测试。

## 工具、技能或 MCP 不可用

检查扩展是否已启用、服务是否可达、权限是否足够，以及相关凭据是否有效。不要在公开渠道提交完整配置、访问令牌或未脱敏日志。

## 提交问题前

请准备：QAgent 版本、操作系统版本、可复现步骤、预期结果和实际结果。截图和日志应先移除密钥、个人信息、私人文件内容与本机绝对路径。

如果问题涉及账户、数据泄露或安全风险，请不要在公开渠道披露细节，应通过产品公布的私密安全联系方式反馈。
