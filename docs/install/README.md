# 安装 QAgent

## 1. 获取安装包

从 [下载与校验](../../downloads.md) 列出的官方发行入口下载与你的系统匹配的 QAgent 安装包。下载完成后，先核对版本号和 SHA-256。

## 2. 在 macOS 上安装

1. 双击下载的 `.dmg` 文件；
2. 在打开的安装窗口中，将 **QAgent** 拖入 **Applications（应用程序）**；
3. 弹出安装磁盘；
4. 在“应用程序”中打开 QAgent。

首次启动时，系统可能显示来自网络下载的应用确认提示。请确认应用名称、来源和文件校验值均正确后再继续。

## 3. 首次使用前的准备

启动后按欢迎界面完成语言和外观等基础设置，然后进入 **设置 → 模型**：

1. 添加你使用的模型服务商；
2. 填写服务商名称、接口地址和访问密钥；
3. 添加可用模型；
4. 选择一个主模型作为默认模型。

访问密钥仅应保存在你自己的设备或受控凭据系统中，切勿发送到聊天、截图或公开问题单中。

## 更新与卸载

- **更新**：下载新版本，核对校验值后按发行说明操作。更新前请阅读该版本的已知限制和数据迁移说明。
- **卸载**：退出 QAgent 后，将应用移至废纸篓。若需要一并清除本地设置和数据，请先查看对应发行版的卸载说明；删除本地数据通常不可恢复。

遇到无法打开、权限提示或启动失败，请先阅读 [故障排查](../troubleshooting/README.md)。
